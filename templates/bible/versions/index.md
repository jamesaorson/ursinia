Ursinia will host free full-text versions of the bible for users to view
and download at their leisure.

- [English Standard Version](/bible/versions/esv) — PDF only
- [King James Version](/bible/versions/kjv) —
  [read the full text](/bible/versions/kjv/text/)
- [Berean Standard Bible](/bible/versions/bsb) —
  [read the full text](/bible/versions/bsb/text/)

The full-text versions carry an anchor on every verse, so any verse can be
linked directly: `/bible/versions/bsb/text/#genesis-1-1`. Both versions share
the same anchors.
