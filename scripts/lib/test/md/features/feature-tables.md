A table needs a header row and a delimiter row.

| Author | Work | Date |
| ------ | ---- | ---- |
| Aristotle | _Politics_ | c. 350 BCE |
| Aquinas | [_De Regno_](https://example.com) | c. 1267 |

The delimiter row sets each column's alignment.

| Left | Center | Right |
| :--- | :----: | ----: |
| a | b | c |

Rows shorter or longer than the header are padded or truncated to fit.

| One | Two | Three |
| --- | --- | ----- |
| only one |
| a | b | c | d |

Leading and trailing pipes are optional, and \| is a literal pipe.

Author | Work
------ | ----
Bodin | Six \| Books
