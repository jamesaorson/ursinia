Reference links let a destination be declared once and cited many times.

The full form names a key: [_Politics_][politics], and again [Aristotle][politics].

The collapsed form reuses the label as the key: [politics][].

The shortcut form drops the brackets entirely: [politics].

A definition may point at an anchor in the same document: [the inventory][ix-3].

An inline [link](https://example.com/inline) still wins over a reference link.

An unresolved key keeps its original text, so **[CLAIM]** and [EV] are untouched.

1. Plato, _Republic_ {#ref-republic}
