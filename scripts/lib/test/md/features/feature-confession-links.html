Citations of the two confessions link out by chapter and paragraph.

A paragraph citation names both numbers: LBCF 23.4 and WCF 22.3.

A chapter citation links to that chapter's first paragraph, since the source publishes no chapter-level page: LBCF 23 and WCF 23.

The spelled-out and abbreviated names both work: Second London Baptist Confession (1689) ch. 26, Westminster Confession ch. 22, 2LBCF 8.2, 1689 ch. 24.

A name with no number is not a citation, so bare LBCF and Westminster are left alone, and so is prose like the 1689 revision of WCF 23, or a 1689 Baptist.

A citation that ends a sentence keeps its period outside the link: WCF 23.

Existing links are never nested: LBCF 23.4.

Code spans are left alone: `LBCF 23.4`.
