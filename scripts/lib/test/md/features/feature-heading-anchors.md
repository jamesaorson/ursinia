# Heading With Explicit Anchor {#custom-title}

A heading may carry its own id instead of one derived from its text.

## Derived From Text

This heading has no marker, so its id comes from the heading text.

#### Trailing Punctuation Is Kept {#punctuated}

Heading text is preserved exactly; only the marker is stripped.

##### Braces {not an anchor} In A Heading

A brace group that is not a well-formed marker stays literal.

###### Empty Marker {#}

An empty marker stays literal too.
